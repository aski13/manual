Система авторизации на PHP

🔹 Основные возможности

  • 📝 Регистрация новых пользователей
  • 🔐 Безопасный вход с проверкой пароля
  • 🚪 Выход из системы
  • 🛡️ Защита страниц через сессии
  • 💾 Хранение данных в MySQL

📌 Краткая инструкция

1. Регистрация

Заполните форму: имя пользователя, email и пароль (минимум 6 символов)

2. Вход в систему

Используйте свои учетные данные для авторизации

3. Защищенные страницы

После входа вы получите доступ к закрытым разделам

Важно: Для работы системы требуется PHP 7.0+ и MySQL 5.6+

🛠️ Внедрение в ваш проект

// В начало защищенных страниц добавьте:
<?php
session_start();
if (!isset($_SESSION['user_id'])) {
  header("Location: auth.php");
  exit();
}
?>

1. Скопируйте файлы в папку вашего проекта

2. Импортируйте SQL-структуру базы данных

3. Настройте подключение к БД в auth.php
